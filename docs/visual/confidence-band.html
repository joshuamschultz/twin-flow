Why one run is a lie

A real floor is random — cycle times vary, scrap happens. Run it once and you get one number. Run it many times and you get the honest answer: a range. This is what twinflow does, live.

The single number the first run gave you sits somewhere in that band — and you had no way to know where. twinflow reports the whole band, so you stop quoting a date you cannot hit. See running.md and concepts.md.
